# AI Usage Disclosure — FoodBridge

## Overview

AI tools, including ChatGPT, were used as development assistants throughout the planning, implementation, debugging and documentation of FoodBridge.

AI assistance supported the development process, while the application was configured, tested and deployed through hands-on work.

## How AI Was Used

AI assistance was used for:

- Brainstorming and refining the FoodBridge concept.
- Planning the application structure and user experience.
- Assisting with React and TypeScript implementation.
- Debugging errors and improving existing code.
- Guiding Supabase database integration and authentication.
- Developing the administrative dashboard.
- Designing the public, read-only judge dashboard.
- Explaining database functions, access policies and application logic.
- Improving project documentation and explaining technical concepts.

## Human Contribution

The project involved hands-on development and decisions, including:

- Setting up and configuring the development environment.
- Building and testing the application locally.
- Creating the Supabase project and database tables.
- Configuring Row Level Security policies.
- Setting up authentication and authorised administrator access.
- Integrating donation, NGO and volunteer submission forms with Supabase.
- Developing and testing the administrative dashboard.
- Implementing the public judge dashboard and its limited-data retrieval function.
- Configuring environment variables.
- Managing the project through GitHub.
- Deploying the application using Render.
- Testing the live website and its routes.

AI suggestions were reviewed and incorporated as part of the development process.

## AI at Runtime

FoodBridge does not currently use an AI model to make decisions, generate predictions or process submissions inside the live application.

AI was used as a development aid rather than as a runtime feature.

## Transparency and Current Limitations

The current platform supports:

- Online donation, NGO and volunteer submissions.
- Database storage through Supabase.
- Authenticated administrative access.
- Submission review and status management.
- A public, read-only dashboard showing limited submission information.

Features such as automated food matching, pickup optimisation, AI-powered recommendations, notifications and verified delivery tracking are future possibilities. They are not presented as completed functionality.

## Responsible AI Use

AI was used to support learning, development and problem-solving. The goal was to build a working application, understand the technologies involved and be transparent about the role AI played in the process.
