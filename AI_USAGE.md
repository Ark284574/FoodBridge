# AI Usage Disclosure — FoodBridge

## How AI Was Used

AI tools, including ChatGPT, were used as development assistants throughout the creation of FoodBridge.

AI assistance was used for:

- Brainstorming and refining the project concept.
- Planning the application structure and user experience.
- Assisting with React and TypeScript implementation.
- Debugging errors and improving existing code.
- Guiding Supabase database integration and authentication.
- Developing the administrative dashboard.
- Improving project documentation and explaining technical concepts.

## Human Contribution

The project was developed through hands-on work and decisions by the builder, including:

- Setting up and configuring the development environment.
- Building and testing the application locally.
- Creating the Supabase project, database tables and access policies.
- Configuring authentication and environment variables.
- Testing donation, NGO and volunteer submissions.
- Integrating the application with GitHub.
- Deploying the website using Render.
- Reviewing and testing the application's functionality.

AI suggestions were reviewed and incorporated as part of the development process.

## AI at Runtime

FoodBridge does not currently use an AI model to make decisions or generate predictions inside the live application.

AI was used as a development aid rather than as a runtime feature.

## Transparency

The current platform supports online submissions, database storage, administrator authentication, submission review and status management.

Automated food matching, pickup optimisation, notifications and verified delivery tracking are future possibilities and are not presented as completed features.

We believe responsible AI use means being transparent about where AI helped and what was actually built.
